## 高可靠、可访问的来源

- **ipaiban.com（i排版官网博客）** — 技术规范类内容权威，实测数据清晰，直接发布运营规则手册。访问正常。
- **woshipm.com（人人都是产品经理）** — 运营策略类内容主流来源，内容质量参差但头条文章可信。访问正常。
- **53ai.com** — 技术实现类（MCP、AI工具）内容可靠，有实操细节。访问正常。
- **zhuanlan.zhihu.com（知乎专栏）** — 部分文章返回 403，需备用。内容质量依赖作者，编辑器评测类文章注意广告倾向。
- **jzl.com（精准流量）** — 算法机制分析可靠，但 SSL 证书问题导致直接 fetch 失败，需通过搜索摘要获取。

## 访问受限的来源

- **blog.csdn.net** — SSL 证书问题，直接 fetch 失败（`unable to get local issuer certificate`）
- **jzl.com** — SSL 证书问题，同上
- **zhuanlan.zhihu.com** — 部分 URL 返回 403，需尝试多次或使用搜索摘要

## 调研注意事项

- 微信官方规范类内容（尺寸、字数限制等）优先查 ipaiban.com 的"运营规则手册"系列，数据精准。
- 算法机制类内容无官方披露，第三方分析均为推测+测试，标注"[不确定]"时置信度约 60-70%。
- 2025 年以前的 SVG 技术文章（segmentfault、cnblogs）内容可能已过时，需与 2025 年实测案例交叉验证。

**Why:** 首次进行微信公众号调研时发现多个来源存在 SSL/403 访问障碍，提前记录避免重复尝试低效来源。
**How to apply:** 遇到微信运营调研任务时，优先使用上述"高可靠"来源；碰到 csdn/jzl 时改用搜索摘要提取要点。
