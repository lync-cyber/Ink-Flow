## 操作规则

### 1. 被动句 → 主动句
- "数据被存储在..." → "系统把数据写入..."
- "请求被转发到..." → "网关把请求转给..."
- "配置被加载后..." → "加载完配置之后..."

### 2. 删除过渡句
- 删除所有起承转合的过渡句（"接下来我们来看..." → 直接开始下一节）
- "让我们先来了解一下..." → 直接开始
- "在深入讨论之前..." → 直接开始
- "值得一提的是..." → 直接说那件事

### 3. 长句拆分
- 句子超过 40 字必须拆成两句
- 拆分时保持因果/转折关系清晰
- 优先在"但是"、"因此"、"所以"处断句

### 4. 冗余首句删除
- 检查每段第一句：删掉后段落仍成立则删掉
- 典型冗余首句: "关于 X，有几点需要说明"、"在讨论 Y 之前"、"首先需要了解的是"

### 5. 自检
- 润色后通读全文，确认信息无损失
- 确认没有因删除过度导致逻辑断裂
- 确认整体语气一致（不能部分段落口语化、部分段落书面化）
