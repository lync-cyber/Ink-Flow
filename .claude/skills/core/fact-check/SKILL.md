## 事实核查清单

### 1. 代码一致性
- 文中引用的代码路径、类名、函数名、参数值是否与源码一致
- 代码示例是否可运行（至少语法正确）
- API 调用是否使用了正确的方法签名

### 2. 时效性信息
- 版本号、发布日期等时效性信息是否过期
- 引用的工具/库是否仍在维护
- 统计数据是否标注了时间范围

### 3. 论点支撑
- 每个论点是否有代码/数据支撑，还是在空谈
- 对比分析是否公平（不cherry-pick有利数据）
- 引用的第三方观点是否准确（非断章取义）

### 4. 读者价值测试
- 读完能带走的不是"了解了 X"，而是一个可迁移的设计判断
- 每个 section 是否有可操作的 takeaway
- 代码示例是否足够完整，读者可以直接参考
