# 微信公众号排版工具（wechat-typesetter）

一个轻量、可本地运行的微信公众号自动排版工具。

支持将 Markdown / HTML / 纯文本快速转换为更适合公众号编辑器粘贴的 HTML（含样式内联与兼容清洗），并提供实时预览、主题切换与一键复制。

## 1. 快速开始

在 `tools/typesetter` 目录执行：

```bash
npm install
npm run dev
```

启动后打开终端输出中的本地地址（默认通常为 `http://localhost:5173`）。

## 2. 常用命令

```bash
npm run dev      # 本地开发
npm run test     # 运行单元测试
npm run build    # 打包生产构建
npm run preview  # 预览构建产物
```

## 3. 使用步骤

### 第一步：输入内容

左侧输入区支持：

- 直接粘贴 Markdown
- 直接粘贴 HTML
- 粘贴纯文本（会按段落自动整理）
- 点击 `Import file` 导入本地文件（`.md/.markdown/.txt/.html/.htm`）

### 第二步：选择主题

顶部可切换主题（学术前沿 / 行业趋势 / 技术专题 / 人物故事）。

如果你的内容 frontmatter 含 `column`（例如 `column: tech`），工具会自动切换对应主题。

### 第三步：调节排版参数

可在参数栏调节：

- 字号
- 行高
- 字距
- 页面边距
- 代码高亮开关
- 图片圆角/阴影
- 公众号名称（用于文末区域）

这些配置会自动保存到浏览器 `localStorage`，下次打开仍会保留。

### 第四步：预览并复制

- 右侧为接近公众号宽度（375px）的预览区
- 点击 `Copy rich text` 一键复制
- 可切换 `</>` 查看最终 HTML 源码

复制时会自动进行兼容清洗（例如移除脚本、样式标签、`id/class` 等），降低粘贴到公众号后台后的异常风险。

## 4. 输入格式建议

### Markdown 推荐元素

- 标题：`#` / `##` / `###`
- 引用：`>`
- 列表：`-` 或 `1.`
- 代码块：````` ```lang ````` 
- 表格：标准 Markdown 表格
- 图片：`![alt](url)`

### 扩展块（可选）

支持 `:::card`、`:::cta`、`:::footer` 等扩展块（具体样式与主题相关）。

## 5. 微信兼容说明

工具已做基础兼容处理，但公众号后台仍可能对部分样式二次重写。建议：

1. 先在工具内预览
2. 粘贴到公众号草稿箱后再快速检查一次
3. 特殊内容（复杂 SVG、外链样式）按实际效果微调

## 6. 常见问题

### Q1：为什么粘贴后样式和预览有少量差异？

公众号编辑器会对部分标签和样式进行重写，这是平台行为。工具的目标是“尽量接近 + 稳定可用”，不是像素级一致。

### Q2：HTML 导入后格式变化了？

导入 `.html` 时会先转换为 Markdown 再走统一排版流水线，复杂嵌套结构可能被简化。

### Q3：复制失败怎么办？

工具会优先使用现代 Clipboard API，失败时自动降级为文本复制。可尝试：

- 使用 HTTPS 或 localhost 环境
- 检查浏览器剪贴板权限
- 切换到源码模式手动复制
