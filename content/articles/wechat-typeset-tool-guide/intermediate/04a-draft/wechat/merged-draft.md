# 微信公众号排版神器 wechat-typeset：从排版痛苦到一键美化

> 公众号排版值得一次性解决，而不是每次发文都重来一遍。

## 01 ／ 你每篇文章，有多少时间是在"调样式"上

你是不是也这样——文章写完，打开 Markdown Nice，选主题，调字号，换颜色。

复制，粘贴进公众号后台。一看，间距歪了。回去再调一轮，再粘一次。这种来回大概要折腾 20 到 30 分钟。

<p class="pullquote">排版吃掉你 30% 的创作时间，却不产生任何内容价值。</p>

有数据算过这笔账：一篇公众号文章从 Markdown 到发布平均 45 分钟，其中 70% 的时间耗在样式调整上 [1]。也就是说，你真正写作之外，每周还要额外掏出一两个小时，干的是跟内容本身毫无关系的事。

<!-- FIGURE: fig-01 -->

更尴尬的是，调完了效果也未必稳。这一篇好看，下一篇同样的操作可能又错位。样式问题反复出现，解决方法却永远是"再调一次"。

这篇文章想聊的工具叫 wechat-typeset。它把"选风格到一键复制"这件事压缩到了 30 秒——而且，你可以用 AI 做出属于自己的排版风格。

---

## 02 ／ 跟 AI 说"我要科技感强一点"，主题就做好了

这是最让我觉得"时代真的变了"的一个功能。

以前想要一套属于自己的排版风格，你得会 CSS，得懂字体搭配，得知道微信后台会把哪些样式吃掉。门槛高到只能请设计师或者将就用公版。

现在不一样。你跟 AI 说一句"我要深色背景、科技感强一点，代码块像终端那种黑底绿字"，AI 就把一整套主题给你生成出来——配色、字间距、提示块样式、分隔线花纹，全套。

<!-- FIGURE: fig-02 -->

更关键的是**自动校验**这一步。微信后台有很多奇怪的限制，有些样式贴进去会被直接吃掉。以前你得踩坑才知道哪些能用哪些不能。

现在 AI 生成完，工具会自己跑一遍检查，不符合微信规范的地方 AI 自动改，改到能用为止。整个过程你不用懂背后发生了什么，拿到的就是一套能直接贴进公众号、不会塌的主题。

这跟市面上其他"AI + 排版"的路子完全不同。壹伴的 AI 是帮你**写文字**，wechat-typeset 的 AI 是帮你**做主题**——一个管内容，一个管外观，是两件事。

> [!TIP]
> 如果你在用 Claude Code 或 InkFlow 写作流水线，排版这一步会在生成草稿之后自动触发，连打开浏览器都不用。

## 03 ／ 9 种"文章人格"——换掉的不只是颜色

大多数排版工具说的"换主题"，其实就是换配色。蓝的变绿的，灰的变黑的，骨架还是同一套。

wechat-typeset 不是这个思路。它的每套主题是一整套**视觉人格**。

打个比方。同一个人，穿正装开会、穿运动服跑步、穿汉服逛展——换的不只是颜色，是整个气质。你不会说"这是同一件衣服换了颜色"，你会说"这是三种不同的状态"。

工具内置 9 套主题，每套对应一种内容气质：

- **科技极客**：深色底、等宽字体、代码块偏终端风
- **财经商务**：克制的灰蓝，字间距紧凑，引用块带细边框
- **文学人文**：衬线字体，段落间距宽松，分隔线是花纹样式
- **生活美学**：柔和配色，圆角元素偏多
- ……另外还有行业观察、教程指南等几套

<!-- FIGURE: fig-03 -->

换主题时，不只是颜色变了——字间距、段落留白、提示块的边框样式、分隔线是直线还是花饰，全部联动变化。同一段文字换两套主题渲染出来，像是两个不同的刊物。

这件事对持续做公众号的人价值很大。你的技术文章固定用一套，生活分享固定用另一套，读者看到排版就能认出"这是那个号的什么类型内容"。视觉身份自然就立住了。

除了主题之外，工具还提供了 20 多种"内容组件"——步骤卡、金句卡、对比块、提示框等等。这些组件会跟着你选的主题走，你选了科技极客风，金句卡就是科技极客版的；换成文学人文，同一个金句卡就自动变成衬线、米色底的样子。

<p class="pullquote">主题不是换皮，是换一个人。</p>

## 04 ／ 粘贴进去，样式永远不会"塌"

公众号排版最崩溃的瞬间不是调样式，是**调完粘进去又塌了**。

预览里一切正常——标题居中、提示块有边框、代码块背景是深灰。兴冲冲复制，粘进公众号后台，一看：边框没了，背景变白了，行距乱了。再回去改，改完再贴，还是不对。反反复复两三轮，才能勉强收敛。

原因是其他工具的预览跟微信后台的渲染环境不是一回事。预览告诉你的只是"大概这样"，真正粘进去之后微信会按自己的规则再加工一遍——有些样式它直接扔掉，有些它给你改写。所以预览再好看都不作数。

wechat-typeset 把这条路堵死了。它的硬纪律是一条：**预览窗里看到的，就是你粘贴后公众号里的样子**。一致，零误差。

> [!IMPORTANT]
> 预览里是什么样，粘贴进去就是什么样。这是工具的硬纪律，不是口号。

工具怎么做到的？有两点值得一提。

一是预览窗的宽度是 375 像素，正好是手机屏幕的宽度。你在预览里看到的排版，就是读者在手机上看到的——不是电脑上好看、手机上错位。

二是那些坑微信会踩的坑，工具已经提前处理过了。<!-- USER_FILL: 作者可以在这里补充一个自己曾经遇到过的、粘贴后样式塌掉的具体经历，比如"我以前在 Markdown Nice 里调好的一个对比表格，贴到公众号里边框全没了，又重新调了半小时" --> 比如某些手机型号不支持特定的排版方式，会导致版式错位。这类问题工具内部自己消化，用户完全不用关心。

顺带一提，工具全程跑在你自己的浏览器里。不用注册账号，不上传草稿，不联网。文稿安全这件事，不用额外操心。

## 05 ／ 三步上手，下一篇文章就能用

说实用的部分。整个上手流程 10 分钟之内，第一篇就能用上。

**第一步**：打开终端，粘贴下面两行命令启动工具。

```bash
git clone https://github.com/lync-cyber/wechat-typeset.git
cd wechat-typeset && npm ci && npm run preview
```

工具会在 `http://127.0.0.1:7788` 起一个本地服务。这个地址只在你自己电脑上能访问，别人看不到。

**第二步**：浏览器打开那个地址，把你写好的 Markdown 草稿粘进去。左边挑一套跟文章气质合适的主题——技术文选科技极客，读书随笔选文学人文，不用纠结，不合适随时换。

**第三步**：点"一键复制"，回公众号后台编辑器里 Ctrl+V。排版完成，可以发布。

跟同类工具对比一下，你能看到它的位置：

| 工具 | 收费 | AI 能力 |
|------|------|---------|
| Markdown Nice | 免费 | 无 |
| doocs/md | 免费开源 | 无 |
| 壹伴助手 | 付费订阅 | AI 写文字 |
| **wechat-typeset** | **免费开源** | **AI 做主题** |

Markdown Nice 和 doocs/md 都稳定好用，但主题同质化，也没有 AI 能力。壹伴对非技术用户最友好，缺点是要付费，而且它的 AI 帮的是写文字的忙，不是排版。

wechat-typeset 的交换条件很清楚：**免费开源、唯一的 AI 主题生成工具，代价是你需要在电脑上跑那两行启动命令**。一次性的事，不用每次都做——启动之后让它在后台挂着就行，草稿会自动存在浏览器里，刷新不丢。

> [!NOTE]
> 工具需要电脑装过 Node.js（版本 18 以上）。没装过的话，去 nodejs.org 下一个安装包，点下一步就行，不用配置什么。

如果你每周都在写公众号，这件事值得一次性解决。10 分钟克隆工具，给你常写的两个栏目各绑一套主题，从下一篇开始排版这件事就不再占用你的创作时间。

先收藏这篇。下次写完草稿准备排版前，打开这里，照着第五节的三步走一遍。
